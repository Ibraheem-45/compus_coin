# 🎓 Campus Coin — Student FinTech & Campus Cashflow Intelligence

A modern, high-conversion commercial Laravel SaaS designed for university student budgeting, daily allowance pacing, expense logging, roommate bill splitting, and institutional administration.

## 🌟 Key Features
* **Emerald + Gold Jungle FinTech Theme:** Professional high-contrast UI across Student and Admin consoles.
* **AI Safe-to-Spend & Daily Burn Meter:** Real-time allowance calculation pacing student expenditure over remaining calendar days.
* **Roommate Bill Splitter:** Instant calculations for hostel mess, electricity, and shared dues.
* **Multi-Currency System:** Enterprise PKR and USD real-time currency conversions.
* **Administrative Governance:** Full audit watchlist, announcement broadcasts, category management, and saving tips library.
* **Plug & Play:** Zero complex dependencies. Compatible with SQLite and MySQL.
