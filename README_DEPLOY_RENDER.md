# 🚀 How to Host Campus Coin on Render.com (100% Free)

This project has been pre-configured with **Dockerfile** and **render.yaml** for instant 1-click deployment on Render.com's Free Tier.

---

### Step 1: Push Code to GitHub
1. Open your GitHub account: [https://github.com](https://github.com)
2. Click **New Repository** and name it `campus-coin`. (Keep it Private or Public).
3. Push your project files to this GitHub repository.

---

### Step 2: Deploy on Render.com
1. Go to [https://render.com](https://render.com) and Sign In (Free).
2. Click the **"New +"** button at the top right and select **"Web Service"**.
3. Select **"Build and deploy from a Git repository"** and choose your `campus-coin` repository.
4. Render will automatically detect the **Dockerfile**!
5. In the settings:
   * **Name:** `campus-coin` (or any custom name)
   * **Region:** Any (e.g. Frankfurt or Oregon)
   * **Instance Type:** **Free**
6. Click **"Deploy Web Service"**!

---

### Step 3: That's It! 🎉
Render will build the Docker container, run migrations, and provide you with a **permanent free public link**:
👉 `https://campus-coin.onrender.com`

You can share this link directly with buyers or paste it into your marketplace sales page as the **Live Demo URL**!
